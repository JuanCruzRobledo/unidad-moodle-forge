### 5. Certificado (mod_customcert) — solo estructura, no HTML propio

El "Certificado"/Constancia es un módulo de tipo **customcert** (no un Label ni una
Página) — Moodle genera el PDF del certificado automáticamente a partir de una
plantilla configurada en el propio módulo, no a partir de HTML que redacte la
cátedra. Lo único relevante para replicar conceptualmente es la **restricción de
acceso** que confirmamos en vivo: el certificado queda oculto/bloqueado hasta que
la actividad de Entrega correspondiente esté "marcada como realizada" (o, en
variantes reales, hasta que se cumpla una condición de fecha o de dirección de
correo institucional). No hay HTML de contenido para calcar acá — solo la regla
de gating: **1 assign de Entrega → 1 customcert de Constancia, con restricción de
disponibilidad atada al estado de esa Entrega.**

## Qué se descartó a propósito (duplicado / oculto / legacy) — NO replicar

- **Variantes por mesa de examen/recuperatorio/extraordinario**: el curso real
  tiene, para cada parcial, 2-4 módulos de "Entrega" casi idénticos (normal,
  recuperatorio, extraordinario con fecha específica) y hasta 3 `customcert`
  distintos con restricciones de acceso distintas (por grupo, por fecha, por
  email). Es ruido operativo de gestión de mesas de examen de una cátedra real
  con años de uso — la plantilla nueva modela **una sola instancia canónica**
  (consigna → entrega → certificado) y deja a criterio del docente clonarla si
  necesita variantes.
- **Resource "Trabajo Practico Integrador - JPA"**: es un PDF alternativo para
  una variante tecnológica específica de Programación 3 (JPA vs. Spring Boot),
  junto con una segunda tarjeta "Recursos disponibles" (plantilla base para el
  back + datos para consumir desde el front). No aplica a materias sin ramas
  tecnológicas paralelas — se documenta como patrón opcional de "recursos
  complementarios descargables", no como bloque obligatorio.
- **"Entrega del Trabajo Integrador para la Mesa de Examen del 27/07/2026"**:
  variante de entrega restringida a un grupo (`REG`) — mismo motivo que el punto
  de mesas de examen arriba.
- **"Entrega del Proyecto Final" (oculta, sin estilo)**: un `assign` con texto
  plano sin ningún formato (ni banner, ni tarjetas) — es contenido legacy /
  cargado apurado, no representa el estándar visual real del aula. Confirma la
  regla ya documentada en `estructura-aula-real.md` ("Inconsistencias reales
  detectadas — NO replicar"): que algo exista en el aula real no lo vuelve
  plantilla válida si rompe el propio estándar visual del curso.
- **"Evaluación del desempeño de tutores" (feedback, oculto por email)**: foro/
  encuesta de gestión interna, fuera del alcance de esta skill.
- **Múltiples `customcert` casi idénticos por parcial** (ej. "Constancia Examen
  Segundo Parcial", "(fecha entrega 04-06-2026)", "(Fecha Emisión 27-05-26)"):
  se registran como el mismo componente conceptual (1 certificado por instancia
  aprobada), no como 3 componentes distintos.
